# Gate 5 网页问答测试题（在 NotebookLM 网页版里提问）

怎么用：打开对应笔记本，把「问题」原样粘贴到对话框，对照「参考答案」。
- 【画面题】答案只在关键帧 PDF 的画面里（屏幕/幻灯片上的字或图），用来验证视觉来源。
- 【语音题】答案主要来自讲话内容（音频来源）。**注意：我没有这两条视频的语音转录，语音题的参考答案是我根据画面上的字幕/标题推断的要点，请以你自己听到的为准；NotebookLM 的回答只要和视频讲的意思一致即算对。**
- 【反例题】来源里没有的内容，正确表现是明确说"来源中没有提到"，而不是编一个答案。
- 判定：每个笔记本 ≥ 6/8 题合格，且反例题没有编造，且回答里出现来源引用（点开能跳到对应来源），即通过。
